# BountiesExpansion-newfix

## 关于 / About
本项目基于 [Shtivi/RDR2-Bounties-Expansion](https://github.com/Shtivi/RDR2-Bounties-Expansion) 二次开发与修正，在原版赏金系统基础上修复问题、补充功能。  
A revised and improved fork of Shtivi's RDR2-Bounties-Expansion, with bug fixes and feature additions to the original bounty system.

## 本次更新 / Changes
- 新增悬赏目标头像贴图资源
- Added bounty target portrait textures
- 修复与 RedDeadLawmen.asi 共存时，佩戴警察徽章后 NPC 停止主动进攻的问题
- Fixed the issue where NPCs stop attacking when police badge is equipped alongside RedDeadLawmen.asi

## 开发计划 / Roadmap
下一版本将实现全动态随机赏金系统：所有任务不再预制，目标、地点、事件均实时生成。  
Next version: fully procedural random bounty system. All missions will be dynamically generated in real time, no more pre-built quests.

## 安装 / Installation
1. 本模组基于 **ScriptHookRDR2 V2** 开发，**未在 Alexander Blade（AB）原版 ScriptHookRDR2 上进行测试**，不保证完全兼容
   This mod is developed on **ScriptHookRDR2 V2**. It has **not been tested on the original Alexander Blade (AB) ScriptHookRDR2**, full compatibility is not guaranteed.
2. 确保已正确安装 ASI 加载器
   Make sure the ASI loader is properly installed.
3. 将模组文件放入游戏根目录
   Copy mod files to the game root folder.

## 说明 / Notice
- 仅适用于 **离线单机模式**，请勿用于线上模式
- For **single-player offline use only**. Do not use in online mode.
